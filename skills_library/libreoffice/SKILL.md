# LibreOffice Automation Suite

Use this skill bundle when automating OpenDocument (`.odt`, `.ods`, `.odp`, `.odg`, `.odb`) workflows with LibreOffice:
- **Writer (`writer/SKILL.md`)**: Document processing and templates.
- **Calc (`calc/SKILL.md`)**: Spreadsheets and formulas.
- **Impress (`impress/SKILL.md`)**: Presentations and slide export.
- **Draw (`draw/SKILL.md`)**: Vector diagrams and flowcharts.
- **Base (`base/SKILL.md`)**: Desktop database queries and forms.
