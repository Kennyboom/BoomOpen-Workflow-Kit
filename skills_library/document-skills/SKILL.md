# Document Skills Suite (DOCX, PDF, PPTX, XLSX)

Use this skill bundle when working with office document formats:
- **Word Documents (`docx`)**: See `docx/SKILL.md` for `.docx` generation and editing.
- **PDF Files (`pdf`)**: See `pdf/SKILL.md` for PDF parsing, form filling, and extraction.
- **Presentations (`pptx`)**: See `pptx/SKILL.md` for slide deck generation and layout.
- **Spreadsheets (`xlsx`)**: See `xlsx/SKILL.md` for workbook formulas, tables, and financial modeling.
