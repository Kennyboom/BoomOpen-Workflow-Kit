# Spec-Driven Development (SPDD)

Use this skill when executing a structured 3-phase Spec-Driven Development workflow:
1. **Phase 1 — Research (`1-research.md`)**: Objective codebase mapping without premature design assumptions.
2. **Phase 2 — Specification (`2-spec.md`)**: Formal technical specification and acceptance criteria.
3. **Phase 3 — Implementation (`3-implementation.md`)**: Disciplined execution and verification against the spec.
