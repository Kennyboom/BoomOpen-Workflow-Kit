# Linear Issue & Project Management Skill

Use this skill when managing Linear issues, projects, cycles, and team workflows.

## Core Capabilities
- **Issue Tracking**: Create, update, prioritize, and transition issues across workflow states.
- **Project & Cycle Management**: Query project milestones, sprint cycles, and progress metrics.
- **Team Workflows**: Coordinate engineering tasks, labels, estimates, and triage queues.
