## 🗂️ SKILL SOURCES & PRE-COMPILED COMPACT INDEX

1. **Active Global Skills (`<skills>`)** — 48 core skills pre-indexed in `~/.{TOOL}/skills/` (`~/.gemini/config/skills/` on Antigravity 2.0) and visible in `<skills>` at turn start.
2. **Pre-Compiled Compact Index (`matrix-skills/compact-index.json`)** — Lightweight JSON dictionary generated by `cli/install.js` mapping every skill ID to `{ domain, priority, category, path }` for millisecond lookup without parsing 1,693-line YAML files.
3. **Dormant Skills Library (`skill-seeker`)** — 1,400+ specialized skills in `~/.gemini/config/skills_library/` searched on-demand.
4. **Domain Matrix (`matrix-skills/{domain}.yaml`)** — Domain-indexed metadata in `~/.{TOOL}/skills/boomopen-workflow-kit/matrix-skills/` (governed by `_index.yaml` and `_dynamic.yaml`).

## SKILL DECISION FLOW

### By Task Complexity

| Assessment | Action |
|------------|--------|
| **Simple** | Base knowledge sufficient — skip skill resolution (`🎯 Skills Analysis: Simple → Skipping`) |
| **Complex** | Run the **Fast 2-Step Lookup** (`<skills>` → `compact-index.json` / `skill-seeker`) and load matching `SKILL.md` |

**⛔ FORBIDDEN**: Outputting `Complex → Using base knowledge (...)` without checking `<skills>` and `compact-index.json` / `skill-seeker`.

### Complex Task Resolution Algorithm

```
WHEN task_complexity == Complex:
  1. CHECK pre-loaded <skills> in system prompt for matching domain/framework skills.
  2. IF found in <skills>:
     → READ the matched SKILL.md directly.
  3. ELSE (niche framework/tool not in <skills>):
     → QUERY ~/.{TOOL}/skills/boomopen-workflow-kit/matrix-skills/compact-index.json
       OR run targeted grep_search in ~/.gemini/config/skills_library/
     → READ the matched SKILL.md file.
  4. IF no local skill exists and variant is :hard or :team:
     → Optionally discover via `npx skills find "{keywords}"` or report gap explicitly.
```

## FITNESS & TRUST PROGRESSION (HSOL)

```
fitness = 0.35 × SEMANTIC_MATCH + 0.25 × SPECIFICITY + 0.20 × TRUST_LEVEL + 0.10 × FRESHNESS + 0.10 × SUCCESS_RATE
```

- **Curated / Matrix skills**: `trust = 1.0`
- **Dynamic skills**: `NEW (0.3) → EVALUATING (0.5, 3 runs) → VALIDATED (0.7, 10 runs) → PROMOTED (1.0, ≥85% success)`
- **Low-trust task-critical skill (`fitness < 0.75`)**: Confirm with user before installing external packages.
